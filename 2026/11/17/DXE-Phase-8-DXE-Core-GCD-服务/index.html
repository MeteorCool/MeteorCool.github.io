DXE Phase 8 DXE Core GCD 服务(1)

​ GCD 是 DXE Core 提供的一组 DXE Services（gDS），不是独立驱动，由 PEI 产出的 HOB 资源描述表初始化，维护启动处理器可见的物理地址空间，分为两张表：GCD Memory Space Map / GCD I/O Space MapUEFI Forum。

核心作用

  1. 统一管理平台地址资源：跟踪物理内存、MMIO、IO Port 区域，标记区域类型（系统内存 / MMIO / 预留）、Cache 属性（WB/WC/UC 等）、占用状态；驱动增删 MMIO、预留资源都走 GCD 接口（Add/Allocate/Free/SetAttribute）UEFI Forum。
  2. CPU 缓存属性的中枢：SetMemorySpaceAttributes 会调用 EFI_CPU_ARCH_PROTOCOL 配置页表 / MTRR，保证内存访问一致性；GCD 是固件视角地址属性的权威记录，和 CPU 硬件属性同步UEFI Forum。
  3. 资源仲裁与防冲突：所有 DXE 驱动申请物理资源必须经过 GCD，避免多驱动争抢同一地址范围；是 PCI 枚举、芯片集驱动、SOC MMIO 分配的基础依赖。
  4. 供查询导出：GetMemorySpaceMap / GetIoSpaceMap 可导出整张资源表，调试、ACPI、OS 启动阶段会参考 GCD 信息UEFI Forum

GCD 管理系统的初始化

​ DxeCore 解析 PEI 传递的资源 HOB，调用 GCD 接口建立物理地址资源表，再由 CPU 架构驱动同步MTRR 缓存属性，完成 GCD 初始化。

从 PEI 交付的 HOB 链里，找到一块满足最小尺寸要求的可用实测系统内存，注册成第一块 EfiConventionalMemory，让 gBS 内存分配、内存池先跑起来，为后续 GCD 全量资源枚举铺路。

第一个hob 需要指向PHIT HOB，PE—>DXE 交接的总入口，里面包含：EfiFreeMemoryBottom / EfiFreeMemoryTop / EfiMemoryTop 这些关键内存边界；

CoreInitializePool()：初始化 DXE 内存池（gBS AllocatePool 的底层），初始化自旋锁、内存池管理结构；

根据PCD 定义执行预定义的固定地址加载 DXE 驱动时，预计算 DxeCodeTopAddress，用于 Runtime/BS 驱动固定地址重定位。

Memory Type Information HOB：记录每种 UEFI 内存类型（BS_Data、RT_Code、RT_Data 等）预估占用页数；

作用：S4 休眠唤醒时，固件需要提前预留足够 Runtime 内存，防止 OS 启动时 Runtime 内存不够；找不到这个 HOB 会打 WARN：S4 resume 大概率失败；

后面如果这个 HOB 和 PHIT 所在的 Resource HOB 是同一块，就丢弃它，避免冲突。

MinimalMemorySizeNeeded：启动 DXE Core 必须的最小内存门槛 = DXE 基础最小内存 + 所有内存类型 bin 需要的总大小； 后面所有内存查找循环都拿这个值做判定，不够就换一块区域。

  1. 第一轮 for 循环：遍历 HOB 链表，筛选已测试系统内存类型的 Resource Descriptor HOB，找到包含 PHIT 自由内存区间的资源 HOB；按优先级尝试提取空闲内存，扣除 PEI 已分配内存，判断是否满足 DXE 启动最小内存需求，满足则选定该内存区域。
  2. 兜底 for 循环：第一轮选出的内存不足时，再次遍历 HOB，跳过 PHIT 资源 HOB 与内存类型信息 HOB，从高地址向低地址查找符合条件、大小足够的可用系统内存，优先保留低位内存给需要 < 4G 的设备。

把 PEI Resource HOB 的资源属性标志，转换成 GCD 识别的内存能力掩码 Capabilities（WB/WC/UC、ECC、可靠内存等）；

MORE_RELIABLE：平台上更高可靠性内存（比如 RAS 内存），标记为EfiGcdMemoryTypeMoreReliable，否则普通系统内存；

这个 Capabilities 后续传给内存描述符，是 GCD / 内存服务识别缓存、硬件特性的依据。

仅当存在独立的 Memory Type Information 资源 HOB 才进入；

给 S4 休眠恢复用：指定一块优先区域，用来预分配 Runtime Code/Runtime Data 等内存 bin；

S4 resume 时固件要提前预留好各类 Runtime 内存，避免 OS 启动时 Runtime 内存耗尽；

没有这个 HOB 就走默认地址上限策略。

向 DXE 内存服务链表注册第一块常规可用内存 EfiConventionalMemory；

RShiftU64(Length, EFI_PAGE_SHIFT)：字节长度转成页计数（UEFI 内存管理以页为单位）；

这一步执行完，BootService 的 AllocatePages、AllocatePool 才真正可用；

将选中的初始内存范围回填输出参数，返回给上层调用方（DxeCore 主流程）；

上层拿到这块内存，继续执行后续：GCD 初始化、BS 表完善、Protocol 数据库初始化、加载 DXE 驱动。
