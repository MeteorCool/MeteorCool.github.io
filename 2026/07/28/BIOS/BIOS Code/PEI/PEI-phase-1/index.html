PEI phase (1)

PEI阶段将会把系统置于初始化的状态，使用一些处理器的资源，比如Cache作为函数的调用栈，来派遣不同的PEI模块去做最基本的系统初始化以保证DXE（驱动执行环境）阶段可以运行，主要包括：初始化系统内存、描述系统内存和固件标签的Flash地址，并且把控制权转交到DXE阶段。同时也需要考虑到唤醒和睡眠的情况，PEI 阶段的代码尽可能精简，S3等情况唤醒可以快速启动。

PEI 整体流程简图如下：

PPI 的基本服务都记录在PEI SERVICE Table，peimain 函数提供这些基础服务。PEI的各个模块可以使用这些服务来完成硬件的初始化，PEI的服务主要包括下面7类：
1.PPI 服务，是各个peiM之间的接口，PPI 管理的相关操作包括安装加载通知等，可以使不同peim之间互相使用彼此的服务，PPI 由peimain维护。

​ 2.启动模式服务，管理系统的启动模式，比如快速启动，冷启动等

​ 3.HOB 服务，用来传递数据到DXE的数据结构

​ 4.FV 服务，管理多个FV 空间。FV 是存储代码和数据的逻辑空间。

​ 5.内存服务，提供内存管理的服务，如申请内存空间等

​ 6.状态编码报告服务，提供普通的进展及错误状态编码的报告服务，这些编码可以通过80 port或者串口输出给用户

​ 7.重启服务，包括冷启动，热启动等

PEI 整个流程由peicore负责，他被SECCORE 调用，主要工作是完成系统初始化，使能PEI的基本服务，通过peidispatcher 派遣所有peim，最后调用dxeipl PPI 去加载dxecore 进入DXE phase。
