环境： Windows 10

Tool ：Qt Creator 20.0.0

和之前linux 使用QT5 不同，新版本的QT6 移除了.pro 工程文件，变更为了 CmakeLists.txt 文件，Cmake可以通过这个脚本文件实现工程的构建。

windows 环境下cmake 可以生成.sln/.vcxproj文件，linux 则是makefile文件。

目前做一个简单的上位机，通过串口和下位机进行通信，所以需要在我的Cmakelist.txt包好串口库

本次案例是上位机通过串口与单片机通讯，完成对双舵机的控制，舵机牵引激光笔一起移动实现激光点位的移动控制。

逻辑信息说明：

1.关于获取当前PC 串口信息

​ Ui初始化调用on_btnRefresh_clicked 函数，该函数活通过 QSerialPortInfo::availablePorts(); 函数获取可用串口列表，通过for 循环降串口列表信息依次写入串口下拉框中

2.串口参数的配置

​ 用户通过下拉框手动选择串口参数，当点击打开串口后，connect 到on_btnOpen_clicked 函数

通过下列函数完成对串口对象m_serial 的参数赋值

m_serial.setPortName(portName);
m_serial.setBaudRate(ui->cbxBaud->currentText().toInt());
m_serial.setDataBits(getDataBits());
m_serial.setParity(getParity());
m_serial.setStopBits(getStopBits());
m_serial.setFlowControl(getFlowCtrl());

3.默认勾选十六进制格式发送

​ 在点击发送按钮，connect 到on_btnsend_clicked函数，通过下列判断将信息转化为16进制发送

if (ui->chkSendHex->isChecked())
    sendBuf = strToHex(sendText);
else
    sendBuf = sendText.toUtf8();
m_serial.write(sendBuf);

4.自动和手动模式的切换

​ ui->stackedWidget：堆叠窗口控件，用来存放两页界面，1表示自动界面，0表示手动界面

​ 点击切换按钮，connect到slotSwitchMode函数，根据m_autoModeFlag状态切换自动，手动模式并改变背景颜色更好区分

5.手动模式下舵机的参数改变与串口命令的计算

​ 当舵机ID，角度，速度有参数改变时，都会connect 到onParamChanged 函数，onParamChanged函数会及时收集修改后的参数并且调用generateCommandHex函数（命令算法）计算出对应的串口命令

6.自动模式下的控制逻辑

​ 自动模式有一组默认的坐标，也可以手动修改，点击开始按钮，connect到slotStartSequence 函数，函数会检测串口状态，检测当前是否处于运行状态，运行则停止计时器，函数返回，反之则通过loadPointsFromUI函数获取6个坐标位置，修改状态，引导进入slotNextPoint函数
slotNextPoint 函数是六点循环的关键，该函数通过定时器溢出完成cennect实现循环操作，当计数器大于6则完成退出

同时，该函数通过sendDualServo函数完成核心发送指令动作

QT 整体上位机程序比较简单，可用用于一些功能调试测试使用，后续会更新一些linux 下QT 联合驱动开发的一些测试案例~
